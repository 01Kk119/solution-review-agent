# 软件领域开发风险索引

## 强制版本顺序

1. 先仅用 5.2.2/250930 能力逐项匹配。
2. 5.2.2 有明确证据且车型、硬件、场景、接口和验收边界一致时停止上探。
3. 只有 5.2.2 明确不支持、适用条件不满足、边界不足或无对应证据时，才加载 5.3.2/260430。
4. 上探时必须记录触发需求、5.2.2差距和5.3.2证据。
5. 5.3.2仍无证据时，标记待确认或疑似非标，不得默认新版满足。

## 评审链路

需求/变化 → 输入输出或流程是否变化 → 影响的软件层 → 版本证据 → 车型/硬件/场景/接口适用性 → 标准配置、版本依赖、标准适配、疑似非标或待确认。

## 疑似新增功能触发

- 新传感器、执行机构或属具没有标准驱动和控制流程。
- 改变车端状态机、安全互锁、超时、重试或异常恢复。
- 新私有协议、字段、握手时序、频率、幂等或回滚机制。
- 新 RCS 调度策略、资源模型、库存规则或业务流程。
- 新 Robotune/HMI/看板/报表/权限/诊断能力。
- 新识别对象、模型、数据格式或特殊安装方式。
- 精度、节拍、规模、稳定性超过测试证据。
- 修改标准接口数据结构、破坏兼容性或维护项目独立代码分支。

## 不直接判非标

- 标准参数范围内调参。
- 地图、点位、区域和交通规则配置。
- 标准接口范围内字段映射和联调。
- 既有工具支持的导入、导出和校验。

以上仍需登记配置、实施、测试和联调人时。

## 必取项目字段

- 单车、RCS/VFS、Robotune、明眸及外部系统版本。
- 车型、控制器/板卡、传感器和属具。
- WMS/WCS/MES/ERP/PLC协议、字段、握手、时序、超时、幂等和回滚。
- 任务来源、状态所有者、异常恢复和人工介入。
- HMI、权限、日志、部署、升级、回退和验收指标。

## 结论分类

`标准能力`、`标准配置`、`版本依赖`、`标准适配`、`疑似非标`、`待确认`、`范围外`。

硬件采购、EHS、安全认证、土建和一般现场整改统一为范围外。

## 必须回查源文件

- 高风险或索引没有对应能力。
- 版本条目标注为计划、增补、仅合并、未测试或未验证。
- 需要承诺车型、接口、精度、性能、稳定性或兼容矩阵。
