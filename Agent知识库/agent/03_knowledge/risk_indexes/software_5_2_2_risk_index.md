# 5.2.2 / 250930 开发风险能力索引

只把源说明中明确标记 `250930` 的条目作为本版本证据；同表中的 `251230` 条目不得算入 5.2.2。

## 可作为匹配证据的能力

| 领域 | 250930能力摘要 | 必核条件 |
|---|---|---|
| Linux/部署 | Docker CPU分配、关闭息屏、`agv`用户与目录权限、桌面/输入法/软键盘 | 客户镜像、账号、权限、日志和IT策略 |
| Robotune/标定 | 日志打包、新参数界面、动态载具、本机清除控制权、标定初始值 | 参数类型、权限、校验和误操作防护 |
| 导航定位 | 多车型手持器地图、10万m²地图、P/E里程计高精对时、MPE自动回环/质量评估、Linux墙角多雷达标定、多车一致性校验、漂移报警 | 车型、地图规模、雷达型号/安装、精度和恢复 |
| 取放/感知 | E大料笼闭环与确认、R货架伺服、ST卸车、机械臂站台反光板伺服、板货堆拆、窄墩/模糊缠膜/网面托盘、精准入叉防撞、伺服横移、新到位逻辑 | 车型、载具、传感器、流程、精度、失败恢复 |
| 软件/固件 | 二阶段取放、货物状态保持、明眸安全功能 | 任务字段、状态机、RCS/车端配套 |
| 明眸 | Web化、单车直联低延迟安全联动、自动标注、隐私、断线提示/重连 | 监控对象、网络、断线动作、三方接口 |

## 不得误算为5.2.2

源表中标记 `251230` 的无明眸装卸车、多尺寸装车、卡板箱、Q200优化、夹抱、音箱直连、VDA5050等，不属于 `250930` 能力证据。

## 5.3.2上探触发

- 客户需求在上表无证据。
- 车型、板卡、传感器、载具或流程不一致。
- 需要半驶离确认、优雅降级、P15-66 RGBD缠膜、插环、长路径滚动下发、Double S、维保计数、Robotune WebSocket/失败诊断等后续能力。

## 输出标记

软件 TPM 必须写：`版本上探5.3.2：否`；若触发上探则写 `版本上探5.3.2：是｜原因：<REQ ID与差距>`。
