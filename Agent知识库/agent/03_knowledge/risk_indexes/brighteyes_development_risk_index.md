# 明眸领域开发风险索引

## 当前能力

| 类别 | 主版本能力索引 | 开发风险触发 |
|---|---|---|
| 库位监控 | 垂直/斜视；单层库位状态；料笼层数；结果上报RCS约500 ms | 新监控对象、多层/复杂堆叠、不同标签、时延更严 |
| 安全监控 | RCS中转总停车约3 s；单车直连链路约340 ms、停车总时约680 ms | 新联动对象、动作、时序、安全状态机或更严时延 |
| 相机 | BOSH NVU-3702-F04；去畸变FOV约82°×50°；RTSP；POE；主版本支持1920×1080/1280×720 | 相机型号、协议、安装姿态或分辨率不同 |
| 服务器 | i7-12700、RTX5070/4070、32 GB、SSD 512 GB；约12路推理 | 相机数、模型数、并发、存储/回放要求超界 |
| 软件 | Web、隐私模糊、断线检测/重连、视频回溯、一键关闭、自诊监控 | 新页面、权限、报表、接口、异常恢复 |
| 网络 | 720p Web预览平均约515.6 ms；12路浏览带宽约105.5 Mbps；多路接口约90 ms | 网络不足、跨网段/安全策略、时延或并发更严 |
| 模型 | 主版本基础模型YOLOv12 l；标签货物/人/车 | 新对象、细分类、遮挡、颜色/材质或新精度指标 |
| 系统环境 | Ubuntu20.04+535/CUDA11.8/TensorRT8.6；或Ubuntu24.04+575/CUDA12.8/TensorRT10.8 | 客户OS、驱动、GPU、容器/安全策略不同 |

## 必取项目字段

- 监控目标、库位层数、货物/料笼外观、遮挡与验收指标。
- 天花高度、相机安装高度、垂直/斜视、覆盖范围和相机数量。
- 服务器/GPU、网络拓扑、带宽、时延、断线和重连策略。
- 与RCS/单车的接口、状态、联动动作和失败恢复。
- 隐私、回放、存储、权限、部署和升级要求。

## 风险分级建议

- 高：新识别对象/标签/模型、新联动状态机、相机或系统环境明显不同、时延/并发超界。
- 中：标准对象但安装、遮挡、网络、数量、验收指标或断线恢复未验证。
- 低：标准相机/服务器/对象/接口组合，只需部署、标定和验收。
