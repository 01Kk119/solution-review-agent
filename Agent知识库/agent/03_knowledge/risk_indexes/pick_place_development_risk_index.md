# 取放非标开发风险速查索引（Agent内部）

> 本文件仅用于Agent快速检索，不是面向TPM的独立知识入口。唯一总入口为：[[capability_specs/pick_place_knowledge/pick_and_place_review_master_guide|取放TPM方案评审总指引]]。

## 强制评审口径

1. 先判断场景是否被目标版本支持，再检查全部边界参数，最后判断是否产生非标开发。
2. 在取放领域，`160版本能力`作为5.2.2的参数边界；此映射不得推广至软件、导航、调度等其他模块。
3. `250930lite`对应5.2.2，`260430`对应5.3.2。
4. `251230`对应5.3.1，是独立版本；不得把5.3.1能力继承、并入或反推到5.3.2。
5. 5.2.2不支持任何货架闭环。
6. 5.3.2支持穿梭式货架闭环，但不支持横梁式货架闭环。
7. 取放规格表是参数和指标的权威来源；会议转写、纪要和XMind用于解释评审方法及版本语义。转写与规格表单位冲突时，以规格表为准。
8. “支持某场景”不等于项目直接标准交付。车型、属具、传感器、版本、载具、特征、间距、精度、节拍、成功率和异常恢复必须全部匹配。

## 一句话评审流程

```text
场景和动作
→ 车型/属具/传感器
→ 载具及检测特征
→ 取货能否识别并安全入叉
→ 放货容差决定普通/检测/闭环方案
→ 核对版本和参数边界
→ 核对失败恢复与跨模块接口
→ 标准配置/待验证/疑似非标
```

## 必取输入

- 目标版本、车型、属具、叉长、横移/俯仰范围、最大举升高度。
- 传感器类型、数量、位置、检测距离和遮挡。
- 取货、放货、堆叠、拆垛、站台、输送线、装卸车或货架场景。
- 载具类型、ID、数量、长宽高、墩、孔、立柱、横梁和底面结构。
- 颜色、材质、反光、透明、缠膜、破损、变形和货物遮挡。
- 取放高度、入叉方向、超托量、左右/前后/顶部净空。
- 停车偏差、目标位置、放货容差、效率和成功率。
- 任务参数由谁下发，失败后如何重试、换库位、退出或人工接管。

信息缺失本身就是风险，不得按“标准支持”关闭。

## 取货风险判断

### 1. 能否认准

- 有载具ID：核对ID与模板、参数、入叉方向的绑定关系。
- 无载具ID：只有现有算法明确支持自动区分时才能采用；培训资料给出的参考条件是托盘特征宽差至少约70 mm。
- 同一载具长边、短边入叉应按不同载具配置处理。
- 多种载具结构接近、参数相近且无ID时，属于错模板和错参数高风险。

### 2. 特征能否检测

- 明确使用墩、插孔、立柱、横梁、整体轮廓、反光板还是视觉标注。
- 卷积托盘检测一般用于间距大于50 mm的常规场景。
- 紧密空间托盘检测一般用于间距小于50 mm的输送线、堆叠或线库。
- 黑色高反、不锈钢、镜面、透明和玻璃属于高风险或不支持对象，必须实物/点云验证。
- 缠膜必须区分纯激光和视觉方案，不能只写“支持缠膜”。
- 载具破损、变形和特征遮挡可能导致“能识别但入叉偏置”，还会继续放大放货风险。

### 3. 能否安全入叉

- 使用载具规格中的货叉与插孔机械容差。
- 同时叠加感知误差、停车/伺服误差、载具变形和举升误差。
- 只要剩余安全余量小于项目验收要求，或组合工况没有验证证据，就不得判为低风险。

## 放货风险判断

### 1. 普通放货

- 容差大时优先使用普通放货或纯定位。
- 仍需核对车辆定位精度、载具尺寸、挡板距离和周边空间。

### 2. 平台检测放货

- 约±15～20 mm容差时，需要平台类墩特征或反光板。
- 类墩参考：墩宽至少50 mm、墩高至少65 mm、墩间距至少100 mm。
- 无类墩时参考两张国四反光板：最小10×10 cm、对称等高、间距至少5 cm。

### 3. 闭环放货

- 小容差必须先确认版本、车型、硬件和闭环对象。
- 料笼/卡板箱闭环与站台反光板闭环是不同方案。
- 普通检测只获取目标位姿；闭环还要实时比较货叉上货物与目标位置并持续纠偏。
- P/E平台闭环规格记录约±8 mm能力，但不能套用到SL/L/R。

## 场景关键边界

### P/E料笼闭环

- 双叉，横移±100 mm，双M感知激光。
- 堆叠容差：至少±7 mm。
- 最大堆叠高度：4500 mm。
- 左右间距L3/L4：300 mm；前后间距：100 mm。
- 下方料笼偏移100 mm/5°时，规格记录可纠偏。
- 容差小于20 mm时，下表面需有支撑梁、梁深大于4 cm，且不能为纯平面。
- 载具变形：不超过±5 mm。
- P车料笼宽度不超过1900 mm；E车不超过3800 mm。

### SL/L/R普通料笼堆叠

- 不支持闭环。
- 举升不超过3 m：容差至少±20 mm。
- 举升不超过4.5 m：容差至少±30 mm。
- 举升不超过6 m：容差至少±40 mm。

### 平台、输送线、旋转台、翻转台

- 5.2.2取放边界采用160列：P/E和SL/L/R均为普通放货，不支持平台闭环。
- P/E普通放货容差至少±15 mm，左右挡板距离至少300 mm。
- SL/L/R不得套用P/E闭环指标。

### 高位货架

- 5.2.2不支持货架闭环。
- 5.3.2只支持穿梭式货架闭环，不支持横梁式货架闭环。
- 5.2.2横梁式普通放货净空参考：
  - 举升≤3 m：左右净空≥210 mm；
  - 举升≤5 m：≥280 mm；
  - 举升≤7 m：≥350 mm；
  - 举升≤9 m：≥450 mm。
- 货架高度、立柱、横梁、遮挡、货物超托和顶部净空仍按取放规格表逐项核对。

### 装卸车

- 5.2.2支持E双叉基础装卸车。
- 5.2.2不支持四叉托盘检测、四叉装车和ST卸车。
- 车厢俯仰/翻滚角、尾门尺寸、登车桥坡度/宽度/中心偏差、车内间距和顶部净空都属于阻断参数。
- 单位必须回查规格表，不能采用会议自动纪要中的厘米转写。

## 非标开发触发

满足任一项即登记“疑似非标/版本缺口”，由研发确认：

- 目标版本不支持场景或功能。
- 车型、属具、传感器或算法组合不在规格范围。
- 新载具、新特征、新材质或新缠膜方案需要训练/标注/算法修改。
- 精度、间距、举升、宽度、变形、效率或成功率超边界。
- 新增闭环、横移、俯仰、不完全入叉、混堆、动态搜索或堆叠确认。
- 新增失败换库位、重试、人工接管或状态回滚逻辑。
- 需要RCS新增任务参数、载具ID、模板绑定或多载具切换流程。
- 需要固件新增到位判断、动作状态机、安全互锁或错误码。
- 需要为项目建立独立模型、独立程序包或独立代码分支。

## 结论分类

- **标准配置**：版本、车型、硬件、场景和参数均有证据，只需配置与验证。
- **标准能力待验证**：能力名称匹配，但材质、尺寸、精度或组合工况未验证。
- **版本缺口**：较高版本有能力，目标版本没有；先做版本决策，不自动等同非标开发。
- **疑似非标**：需要新增或修改算法、状态机、接口、工具或异常流程。
- **资料不足**：缺少输入或证据，不能作支持性判断。
