# 导航领域开发风险索引

## 评审目标

判断地图、定位特征、路径、环境、车辆控制与恢复逻辑能否由现有能力覆盖，重点识别新增定位、建图、路径规划、控制或降级恢复算法风险。

## 必取项目字段

- 地图面积、路线长度、最长连续通道、车辆数量。
- 通道宽高、天花板高度、雷达安装高度与遮挡。
- 墙面、天花、货架、货物的颜色、材质、反光和可变性。
- 室内/半室外/室外、坡度、坡长、雨雪雾、积水、粉尘、打滑。
- 固定路径精度、停车精度、重定位和失效恢复要求。
- 门、电梯、共享通道、动态障碍和高货物遮挡。

## 当前边界

| 边界项 | 当前能力索引 | 开发风险触发 |
|---|---|---|
| 地图规模 | 约100,000 m²；累计里程约2500 m | 更大规模、更多车、性能或更新频率无证据 |
| 无特征通道 | 连续约15 m | 更长；墙/顶均平整且缺少高反特征；激光定位误差可能随行驶距离累计 |
| 天花雷达高度 | 距天花最低约0.2 m、最高约20 m；有效覆盖长度约0.6 m | 超高度、镜面顶、无特征顶或大面积遮挡 |
| 玻璃 | 建议与传感器视线形成约45° | 大面积正对玻璃或反射条件变化 |
| 自动门 | 单个自动门有能力记录 | 多门串联、门状态/失败恢复流程新增 |
| 坡道 | 典型坡度约≤5°、坡长约≤10 m | 更陡/更长、湿滑、起伏或控制指标新增 |
| 固定路径精度 | P/ST/SL满载约±3 cm；E/R/Q满载约±4 cm；空载约±2/±3 cm | 要求更严、验收方法不同或无车型测试 |
| 货架区 | 需要稳定高反或等效特征；固定路径主要支持地面 | 移动货架、驶入式货架、镜面/纯黑/无特征；连续纵深>15 m时按累计漂移高风险评审 |
| 线库存储 | 货物需高出雷达约20 cm；连续约15 m；端点墙距离约<20 m | 长度>15 m、9 m高线库、黑色/强反货物、货位变化导致特征失稳；长度超限按累计漂移高风险评审 |
| 长车厢导航 | 依赖车厢结构、入口和内部稳定定位特征，当前索引无>15 m直接能力证据 | 车厢内部连续导航长度>15 m时，重复侧壁/顶棚和遮挡可能使激光定位累计漂移，按高风险评审 |
| 反光材质 | 反光膜/不锈钢面积建议低于约20% | 大面积反光或动态遮挡 |
| 室外 | 建筑特征建议在约15 m内；反光板间距约<5 m | 纯室外、无固定特征、雨雪雾、积水/结冰 |
| 半室外 | 约15 m内有固定垂直建筑和屋顶 | 无屋顶、天气侵入或湿滑 |
| 登车桥 | 典型坡度约≤5° | 更大坡度、桥体晃动或位置变化 |

## 直接高风险信号

- 导航通道/线库连续无稳定特征超过约15 m。
- 线库、货架巷道或车厢内部的连续导航长度>15 m。此类环境通常具有重复结构、遮挡或弱特征，激光匹配误差难以及时被稳定地图特征校正，可能随行驶距离累计，导致纵向或横向定位偏差、停车点漂移及取放对接失败。
- 镜面、黑色、玻璃、移动货架、驶入式货架构成主要定位环境。
- 纯室外且需要在雨雪雾中稳定作业。
- 客户要求盲取、动态库位搜索或新型重定位/降级流程但无对应能力证据。
- 精度、速度曲线、路径长度或规模超出已验证范围。

## 长距离累计漂移专项规则

### 触发条件

- 场景属于线库、货架巷道或车厢内部导航。
- 单段连续导航长度大于15 m。
- 任一条件满足时即按高风险登记；若同时存在侧壁/顶棚结构重复、货物遮挡、货位变化、镜面、纯黑或缺少高反特征，风险置信度提高。

### 风险机理

- 激光定位依靠连续扫描与地图特征匹配修正车辆位姿。
- 长距离重复或弱特征场景中，相邻位置的激光轮廓相似，单次小误差不容易被可靠特征纠正。
- 小误差可能随行驶距离累计，造成定位不准、路径偏移、停车点漂移、进叉或放货对接失败。

### 必须获取与验证

- 获取线库、货架巷道或车厢的实际连续长度、宽度、高度和完整点云/现场照片。
- 标注入口、端部、侧壁、顶棚、立柱、横梁、高反板及其他稳定特征的位置和间距。
- 明确车辆、雷达型号、安装高度、货物遮挡状态、地图版本、定位版本及目标停车精度。
- 在满载、空载及典型货位占用状态下实测全程定位误差和末端停车偏差，不得只验证短距离或空场景。

### 关闭或降级条件

- 已通过稳定高反或等效定位特征、分段校正/重定位等方案消除长距离累计漂移。
- 专项实测覆盖最不利货位占用和遮挡工况，且全程定位误差、末端停车偏差及取放对接成功率满足验收标准。
- 缺少以上证据时保持高风险，不得仅凭“支持线库导航”“支持货架区导航”或“支持车厢导航”降级。

## 风险分级建议

- 高：环境明确落在不支持项，或核心流程需要新定位/控制/恢复算法。
- 中：边界临界，依赖反光板、专项测试、车型/版本验证或共享通道方案。
- 低：边界内且只需建图、地图配置、标定或参数验证。

## 必须回查源文件

- 任一高风险。
- 需要引用具体高度、距离、坡度、固定路径精度或车型差异。
- 项目含室外、半室外、线库、移动/驶入式货架、长车厢、玻璃或镜面环境。
