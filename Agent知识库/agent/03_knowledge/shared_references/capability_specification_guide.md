# 能力规格说明

# 一、文档目的

本文件用于系统性定义无人叉车产品在当前版本下的**能力边界（Capability Boundary）**。

能力边界是指：在既定产品版本、软硬件配置及算法能力下，系统在真实业务场景中**可稳定实现、可交付、可验证的能力范围**。

本文件的核心价值包括：

1.  **明确产品能力范围**
    
    为销售、方案、交付、研发提供统一的能力认知，避免能力误判与过度承诺。
    
2.  **支撑方案与订单评估**
    
    在项目前期快速判断场景是否匹配当前产品能力，提高签单效率与准确性。
    
3.  **驱动版本规划与技术演进**
    

当市场需求或项目需求与能力规格存在差距时，该差距即构成后续版本迭代的核心输入。

# 二、能力规格与产品演进关系

能力规格并非静态定义，而是处于如下闭环中：

**市场需求 / 项目需求 → 技术握手评估 → 当前能力规格 → 差距识别 → 产品版本规划 → 能力升级**

*   当前版本能力规格：定义“现在能做什么”
    
*   市场/项目需求：定义“需要做到什么”
    
*   二者不匹配部分：定义“下一版本要解决什么”
    

因此，本能力规格文件是**连接市场、产品与研发的核心桥梁**。

# 三、能力验证与测试体系

所有能力规格均需通过标准化测试进行验证，测试体系分为两大类：

### 1）系统级测试（System Level）

在真车和仿真下进行系统测试

用于验证整体系统在真实场景中的稳定性与可靠性，包括：

*   多模块协同稳定性
    
*   长时间运行稳定性（稳定性/MTBF）
    
*   多车协同一致性
    
*   实际场景闭环成功率
    

### 2）模块级测试（Module Level）

在仿真下进行边界指标测试

针对各能力模块进行性能与边界验证，包括：

*   性能指标测试（精度、效率、成功率等）
    
*   能力边界测试（极限工况、容差范围）
    
*   风险场景验证（弱特征、极端环境）
    

# 四、能力规格构成

本文件从多个维度定义产品能力边界，主要包括：

### 1）车体能力规格（Vehicle Capability）

定义各车型在运动与控制层面的基础能力，是所有场景能力的基础。

主要包括：

*   运动学性能（速度、转弯半径、路径跟踪能力等）
    
*   动力学性能（加速度、制动能力等）
    
*   控制参数（行走控制、转向控制等）
    
*   执行机构能力（货叉、液压系统）
    
*   精度指标（定位精度、控制精度）
    

该部分的价值：

*   作为**车辆标准化性能输出依据**
    
*   支撑**一致性测试与出厂测试标准**
    
*   提供**方案阶段效率与可行性评估依据**
    

### 2）载具与取放能力规格（Handling Capability）

定义产品在“取放作业”层面的能力边界。

包括：

#### （1）载具适配能力

*   支持载具类型（托盘、料笼、缠膜托盘等）
    
*   材质适应性（木质、塑料等）
    
*   不支持或高风险载具（反光、透明、黑色等）
    

#### （2）取放环境适应性

*   容差范围（位置偏差、角度偏差、高度偏差）
    
*   入叉空间要求
    
*   地面条件适应性
    

#### （3）场景能力定义

建立“车型 × 场景”的匹配关系，包括：

*   料笼堆叠
    
*   板货堆叠
    
*   高位货架
    
*   输送线对接
    
*   站台作业
    
*   旋转台 / 翻转台
    
*   ST装卸车等
    

并定义每个场景的：

*   核心特征要求
    
*   能力边界（容差/限制条件）
    
*   成功率与效率指标
    

该部分直接用于：

*   **方案设计与选型**
    
*   **项目可行性评估**
    
*   **版本能力规划**
    

### 3）导航能力规格（Navigation Capability）

定义单车在环境中的定位与导航能力边界，包括：

*   可识别环境特征类型（结构特征、纹理特征等）
    
*   不支持或高风险特征（弱特征、重复结构等）
    
*   场景限制（如线库长度、门洞尺寸等）
    
*   定位精度与稳定性要求
    
*   多车一致性要求
    

### 4）调度能力规格（Scheduling Capability）

定义多车系统在不同场景下的调度能力，包括：

*   多车协同能力
    
*   路径冲突处理能力
    
*   优先级与任务调度能力
    
*   特定场景支持情况（如拥堵、停车位占用等）
    

当前调度能力：

*   以**能力支持情况描述为主（粗颗粒）**
    
*   后续将逐步补充为**量化指标体系**
    

### 5）明眸能力规格（Perception System Capability）

定义感知系统（明眸）的功能与性能边界，包括：

*   支持功能（检测、识别、测量等）
    
*   不同版本能力对比（如160版本 vs 当前版本）
    
*   性能指标（识别成功率、稳定性等）
    
*   风险场景说明
    

## 五、版本说明

本文件当前覆盖：

*   **160版本能力规格**
    
*   **最新版本能力规格（如251230）**
    

不同版本之间通过能力对比，体现：

*   能力提升点
    
*   能力边界扩展
    
*   新增支持场景
