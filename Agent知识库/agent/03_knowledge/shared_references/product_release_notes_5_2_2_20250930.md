# 20250930 版本说明

# 一、25年主版本 特性概要

0930版本主要特性如下：

✅ **场景方案**：E车大料笼堆叠全流程闭环，R车货架左右伺服方案，ST卸车新方案，机械臂站台精准堆叠，板货堆叠/拆垛新方案，卡板箱堆叠上线。

✅ **硬件适配与升级**：Q200、自研P/E、夹抱车、标定房车辆自动标定、智能货叉1.0/2.0全平台适配与功能升级。

✅ **取放特性**：托盘精准检测，模糊缠膜托盘识别，智能防撞，伺服效率与横移提升，水平&垂直到位新逻辑

✅ **导航特性**：手持器地图多车型支持，10万平米大地图，里程计高精对时，地图一键回环与质量评估，Linux多雷达标定，导航误差报警

✅ **软件特性**：Linux全线支持，VDA5050标准协议，Robotune全链路优化，Licence授权工具

✅ **库位明眸**：明眸系统Web化，单车安全直连，自动标注工具，隐私保护与断线重连

共计30余个大特性，近90个小特性构成。
