# 人时估算风险索引

## 规则

- 只估算有稳定事项 ID 的已分类工作；不得新增或重分类事项。
- 三点估算：低、最可能、高；推荐值 `PERT=(Low+4×MostLikely+High)/6`。
- 复杂度系数：简单1.0、中等1.5、复杂2.0、高不确定2.5。
- 资料不足写 `not_estimable`，不能填0。
- 不估硬件采购、EHS、土建、客户工作、运输、审批和等待时间。

## 单独估算

新车型/控制器平台、安全/法规认证、大规模算法研究、全新模型架构、客户基础设施施工，以及尚无需求与验收标准的事项。
