# 取放风险识别+相关算法培训

# 订单取放货风险评估讲解框架

## 一、先明确评估输入

开始评估前，先收齐五类信息：

1.  车型、属具、传感器配置和软件版本。
    
2.  取货还是放货，所在场景是什么。
    
3.  载具类型、数量、尺寸和检测特征。
    
4.  是否下发载具 ID、取放高度和目标位置。
    
5.  客户要求的插取或放货容差、成功率和效率。
    

信息缺失本身就是风险，不能直接按“标准场景支持”下结论。

## 二、取货风险：能否认准，能否插入

### 1. 先判断载具能否被正确识别

重点检查：

*   是托盘、料笼、卡板箱还是缠膜载具。
    
*   有几种载具，是否需要区分载具 ID。
    
*   如果没有下发 ID，现有算法能否自动区分（至少墩宽差距7cm）
    
*   检测依赖的是墩、插孔、立柱还是整体轮廓。
    
*   特征尺寸是否达到算法要求。
    
*   检测距离变化后，特征是否仍然足够明显。
    

载具数量越多、结构差异越小，而订单又没有下发 ID，识别错载具或调用错参数的风险越高。

### 2. 再判断有无检测干扰

重点检查：

*   黑色载具：属于高风险项，黑色高反需要验证。
    
*   塑料、普通金属、木材等漫反射材质：一般在现有验证范围内。
    
*   不锈钢、镜面、透明、玻璃：现有边界资料列为不支持或高风险。
    
*   缠膜是否遮挡插孔或形成大面积反光。
    
*   相邻货物、立柱或平台结构是否进入检测区域。
    
*   货物之间的左右、前后间距是否满足场景要求。
    
*   载具是否变形、破损，关键特征是否被货物遮挡。
    

### 3. 最后计算货叉与插孔的机械容差

跟货叉长度和举升高度相关[请至钉钉文档查看附件《载具能力规格》。](https://alidocs.dingtalk.com/i/nodes/EpGBa2Lm8ajE1BwmIDmxN9pnWgN7R35y?cid=74048298874&corpId=ding93a88f01dc7a5a8735c2f4657eb6378f&doc_type=wiki_doc&iframeQuery=anchorId%3DX02ms643op9g20ip81t76&utm_medium=im_card&utm_scene=team_space&utm_source=im)

## 三、放货风险：放货容差决定方案等级

### 1. 容差足够大：优先普通放货法，没有特征用纯定位

当客户的放货容差足够大时，可以采用普通放货。

在站台、输送线、旋转台、翻转台场景中，资料给出的典型判断是：

*   放货容差达到大于±20 mm，对平台检测特征可以没有特殊要求。
    
*   仍需检查车辆定位精度、左右挡板距离、载具尺寸和场景空间。e车定位精度低，有风险，
    

这里的“纯定位”是不依赖检测进行末端纠偏。

### 2. 中等容差：检测平台

当放货容差约为±15～20 mm时，需要关注平台是否可识别：

*   平台有类墩特征：最小墩宽50 mm、最小墩高65 mm、墩间距至少100 mm。
    
*   没有类墩特征时，可配置两张反光板进行平台检测；资料要求对称、等高布置，尺寸至少10×10 cm，间距至少5 cm。
    

此时可以把平台理解成一种“被检测载具”：算法需要从平台结构中求出放货目标位置。

### 3. 很小容差：必须走闭环方案

需要区分放货对象：

*   放到另一只料笼或卡板箱上：评估料笼/卡板箱堆叠闭环。
    
*   放到站台或输送线上：评估反光板闭环。
    
*   不能把“料笼闭环”和“反光板闭环”混成同一个方案。
    

P/E车型资料中，平台闭环可覆盖约±8 mm级容差，但需要：

*   对应的闭环硬件和版本能力。
    
*   后侧挡板宽度至少25 cm，粘贴两张10×15 cm反光板；反光板等高、间距至少5 cm，旁边不能紧靠其他物体；或者
    
*   平台四角具有4个L型平整立柱面，墩高至少70 mm、墩宽至少50 mm，平台宽度不超过3800 mm。
    

SL/L/R当前规格主要是普通放货，不应直接套用P/E闭环结论。

## 四、再按场景检查专项指标

### 1. 平面线库

*   取货左右间距参考：L3、L4约150 mm。
    
*   放货左右间距参考：L3、L4约300 mm。
    
*   取货前后间距D1边界约30 mm，建议至少50 mm。
    
*   放货前后间距D1约50 mm。
    
*   货物高于导航雷达、线库长度超过20 m时，还要评估反光板辅助导航。
    

### 2. 站台、输送线、旋转台、翻转台

重点看：

*   放货容差。
    
*   平台结构和检测特征。
    
*   反光板是否满足尺寸和安装要求。
    
*   载具与左右挡板的距离。
    
*   车型是否支持闭环。
    
*   重力输送线还要检查坡度和插孔上下容差。
    

### 3. 料笼或卡板箱堆叠

重点看：

*   普通堆叠还是闭环堆叠。
    
*   目标容差。
    
*   下层载具的横梁、脚杯或脚墩特征。
    
*   下表面是否为纯平面。
    
*   载具变形。
    
*   货物是否遮挡上表面检测特征。
    
*   堆叠高度、天花板净空和周边货物间距。
    

P/E闭环料笼堆叠的容差大于等于±7 mm；当容差小于20 mm时，料笼下表面需要支撑梁结构，梁深大于4 cm，不能是纯平面。

### 4. 高位货架

不能只看放货容差，还要检查：

*   举升高度。
    
*   左右净空随高度的变化。
    
*   高度净空。
    
*   立柱和横梁的宽度、高度、平整度。
    
*   防撞块是否遮挡有效立柱。
    
*   货物超托、倾斜和背靠背距离。
    
*   车型横移能力和高位闭环配置。
    

### 5. 货柜车装卸

单独评估：

*   尾门宽度和高度。
    
*   车厢内前后、左右货物间距。
    
*   货物与车顶的高度净空。
    
*   登车桥宽度、坡度和承载能力。
    
*   车厢与登车桥的角度、中心偏差。
    
*   车厢地板平整度、光照和环境干扰。
