# 硬件需求识别知识（hardware_feature_taxonomy）

> 用途：归类资料中的硬件加装/定制需求。
> 硬约束：只登记与来源，不判断可行性与成本。

## 硬件需求归类

| 类别 | 典型内容 | 记录字段 |
|---|---|---|
| 感知加装 | 相机、单线/多线激光、补盲雷达 | 用途、安装位置、触发场景 |
| 安全加装 | 非接触防撞插件、安全触边、急停 | 覆盖场景、标准依据 |
| 声光 | 三色灯、示廓灯、蜂鸣/鸣笛、频闪逻辑 | 触发条件（转向/停车点等） |
| 交互硬件 | 屏幕、按钮、HMI、PAD | 使用者、位置 |
| 取放属具 | 货叉规格、横移器、定制属具、四叉 | 尺寸、载荷 |
| 能源 | 电池（电压/容量/数量）、充电机（功率/数量）、换电推车 | 数量、位置、供电由谁提供 |
| 车体定制 | 颜色（色号/RGB）、logo、结构件 | 是否非标准色、图样是否提供 |
| 现场设施 | 反光条/柱、二维码、货位标识、护栏、充电站施工 | 数量、位置、由谁施工 |
| 环境适配 | 冷库包、防尘、室外防护 | 环境参数 |

## 疑似非标信号

- 非标准色喷涂、定制 logo（图样/位置未定 → 直接进缺失清单）
- 定制声光逻辑（与标准声光行为不同的现场规则）
- 特殊货叉规格（非标准长度/宽度/厚度组合）、监控余量很小的插取
- 客户指定品牌/型号的部件
- 现场定位辅助设施的安装与维护责任未定

## 安全场景登记（8.2 节）

人车混行、与客户人工叉车/拖车混行、月台边缘、登车桥、盲区交叉口、
高位/双层货物遮挡视线、特殊停车规则点位。
每条写清：什么安全问题 + 出现在哪个场景 + 资料依据；不泛写“安全风险高”。
