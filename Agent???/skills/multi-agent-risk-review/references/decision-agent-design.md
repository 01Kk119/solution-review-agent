# 交付决策 Agent 职责设计

## 设计原则

- 每个 Agent 只拥有一种判断权；后续 Agent 可以引用前序结论，不能改写前序结论。
- 领域 Agent 识别非标准功能开发风险；决策 Agent 把已质检事实转换成交付建议。
- 不设置“定制范围 TPM”。定制化开发附件由全局汇总 TPM 从非标判定结果中筛选生成。
- 硬件选型、EHS、安全认证、土建、施工和一般现场整改统一标记为 `out_of_scope`，不进入进一步判断或人时估算。
- 除全局汇总 TPM 外，所有 Agent 只写各自 trace JSON，不写用户附件。

## 职责矩阵

| Agent | 核心输入 | 唯一判断权 | 明确不负责 | 结构化输出 | 对应附件 |
|---|---|---|---|---|---|
| 取放 TPM | 载具/货物尺寸与容差、关键几何、停靠偏差、取放场景、取放能力基线 | 识别取放需求是否超出标准功能边界及其证据缺口 | 硬件、EHS、土建、现场整改、版本、人时 | `AgentResult(domain=pick_place)` | 主报告领域结论 |
| 版本适配 TPM | 项目需求、已质检风险、版本能力矩阵、发布基线 | 统一确定项目完整版本包、版本风险等级、升级动作和验证计划 | 非标判定、开发范围、人时、按模块拆分版本 | `VersionRecommendationResult` | 版本适配建议 |
| 非标判定 TPM | 项目功能需求、已质检风险、版本结果、标准能力边界 | 对已有功能交付项分类，确认定制开发或真正非标开发 | 新增需求、改写版本、估人时、硬件与现场、商务承诺 | `NonstandardResult` | 定制化开发清单、非标判定清单 |
| 人时估算 TPM | 已分类功能工作项、工时基线、依赖 | 对已有来源 ID 的功能工作按阶段/角色估算低—最可能—高人时 | 硬件与现场；新增或重分类范围；版本/非标判断 | `EffortEstimateResult` | 人时估算清单 |
| 全局汇总 TPM | 全部领域结果、Critic、三个决策结果、输出要求 | 去重、保留冲突、跨文档一致性检查和文件呈现 | 重新做专业判断或填补缺失结论 | 主报告、四份附件、manifest | 全部最终文件 |

## 分类边界

| 分类 | 含义 | 进入定制化开发附件 | 进入非标附件 |
|---|---|---:|---:|
| `standard_capability` | 当前推荐版本原生支持 | 否，进入标准能力组 | 否 |
| `standard_configuration` | 仅需标准参数/规则配置 | 否，进入标准能力组 | 否 |
| `version_dependent_configuration` | 目标版本支持，需升级后配置 | 否，进入版本依赖组 | 否 |
| `custom_development` | 项目专属功能开发，但尚未证明超出产品非标边界 | 是 | 否 |
| `nonstandard_development` | 已确认超出标准版本边界，需新增/修改产品能力 | 是 | 是 |
| `pending_confirmation` | 证据或版本边界不足 | 待确认区 | 待判定区 |
| `out_of_scope` | 非功能开发项，或明确不在本评审范围 | 排除项 | 否 |

## 边界示例

- 托盘只给出 `1200 × 1000 mm` 而没有尺寸公差、叉孔与纵梁尺寸时，取放 TPM 必须输出待确认，不能直接判定标准。
- Stop Sign 等待 5 秒可由交通管制和 RCS 标准配置实现，分类为 `standard_configuration`。
- 声光规则依赖目标版本和标准调试工具，分类为 `version_dependent_configuration`，不自动算开发。
- 若某种异形载具需要新增识别、入叉或落位算法，且推荐版本能力基线明确不支持，才可分类为 `nonstandard_development`。
- 加贴反光板、拆除挡架、供电布线、机柜安装等现场动作不评估，统一为 `out_of_scope`。

## 执行顺序

```text
取放 / 导航 / 调度 / 软件 / 条件明眸
                    ↓
              Evidence Critic
                    ↓
              版本适配 TPM
                    ↓
              非标判定 TPM
                    ↓
              人时估算 TPM
                    ↓
              全局汇总 TPM
                    ↓
          主报告 + 4 份独立附件
```
