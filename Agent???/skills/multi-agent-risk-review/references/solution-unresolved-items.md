# 方案未决项规则

## 定义与边界

| 对象 | 定义 | 必填要求 |
|---|---|---|
| 关键风险 | 已有项目证据表明可能影响能力满足、交付或验收的不利条件 | 必须有风险 ID、高/中/低等级、影响、依据和关闭动作 |
| 待确认事项 | 当前缺少具体事实，无法关闭关联风险或完成方案判断的问题 | 必须有关联风险、暂定等级、责任方和关闭条件 |
| 方案未决项清单 | 第 6 步对尚未闭环的关键风险和待确认事项形成的交付传承文件 | 不新增事实，不重新判断版本、非标或人时 |

关键风险与待确认事项共用关联关系，但不能混为同一类型。一条风险可关联多条待确认事项，一条待确认事项也可关联多个风险。

## 输入来源

不得要求用户新增填写文件。只读取当前运行前面步骤已经生成的产物：

1. 第 5 步证据质检后的有效关键风险，作为风险主来源。
2. 第 4 步领域评审中的 `open_questions`，作为待确认事项主来源。
3. 第 6 步版本适配中明确标为待确认的项目级版本结论。
4. 第 6 步非标判定中明确标为待确认的功能边界。

输入不足时保留“待确认”，不得补造客户事实或现场数据。

不读取第 3 步轻量需求模型，因为相关信息已经被领域评审和证据质检消费；不读取人时估算，因为资源测算不是关键风险或现场信息确认的事实来源。

## 知识分类

以下内容来自《需确认项Map1》，用于检查是否漏问，不代表每个项目都适用：

| 类别 | 检查范围 |
|---|---|
| 车型与能力边界 | 车体尺寸、VNQ/VNK、举升范围、门架、通道、扫码枪、DT35、相机和传感器条件 |
| 取放位置与设备 | 地面、货架、输送线、倾斜台、升降台、旋转台、动态平台、站台和车辆装卸 |
| 货物与载具 | 长宽高、公差、叉孔、底部结构、颜色、反光、覆膜、变形、货物超边和载荷范围 |
| 业务与系统流程 | 起点终点、取放动作、任务来源、载具 ID、扫码、WMS/WCS/PLC 交互和异常处理 |
| 现场环境 | 通道、门、电梯、坡度、地面、水渍、粉尘、光照、反光、吊顶、人车混行和充电条件 |
| 验证与交付边界 | 定位误差、停靠偏差、温度、摩擦系数、信号稳定性、仿真差异、测试方法和验收口径 |

仅当项目资料出现对应场景时检查相关分支。没有项目证据的知识项只能用于提出待确认问题，不能直接升级为当前风险。

## 输出规则

- 文件名：`06_<项目编号>_solution_unresolved_items_<日期>_vNNN.md`。
- 只保留“汇总结论”“关键风险”“待确认事项”三个章节。
- 不输出“按假设推进事项”或“已关闭事项”。
- 已关闭内容不进入本清单。
- 关键风险和待确认事项分别成表，通过风险 ID 关联。
- 同一事项按“领域 + 核心问题 + 关联风险”去重。
- 方案方无法获得的信息应写明无法确认原因，并继续向后续交付阶段传承。
