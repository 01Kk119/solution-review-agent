- `output_sample/`：对 mock 输入执行 `run`（Stage-1 extract + scaffold）后的产物：
  `extracted/manifest.json`、内容单元 JSON、`*.draft.md` 草稿。
  Stage-2（AI 结构化转写正文）的**完整真实示例**见项目根目录
  `output/068_napoleon_tugger_phase2/`（068 二期项目全量资料包，含证据索引与 HTML）。
