# 取放特征识别知识（picking_and_placing）

> 用途：从资料中识别取货/放货场景特征，判断哪些信息影响取放方案，缺什么要追问。
> 硬约束：不下“能不能取”的结论——只整理事实、标注风险线索、列出待确认项。

## 取放场景拆分维度

每个取货点/放货点按以下字段整理（资料没有就写“未在资料中明确提供”）：

- **对象**：取/放什么载具（关联 carrier_taxonomy）
- **位置类型**：地面 / 货架 / 输送线末端 / 车厢内 / 拖挂小车上 / 堆叠层上
- **高度**：取放面高度、堆叠后总高、提升高度需求
- **定位方式**：固定库位 / 输送线端定位 / 需感知定位（托盘检测、料笼检测、货架检测、缓存架检测）
- **对象状态**：是否缠膜、是否歪斜、是否变形、间距（货物-货物、货物-挡板）
- **精度要求**：插孔余量（上下/左右）、放货对位要求（对孔、对格）
- **环境**：光照、逆光、反光、遮挡
- **动作**：单叉/多托、是否需要横移、是否需要微调、是否二次调整空间

## 识别/感知需求信号（出现即记录并归到 5.x）

- “视觉识别 / 点云 / 相机 / 检测 / 定位精度 / 反光条 / 二维码” → 感知定位手段
- 停放偏差角度、位置浮动量（如 ±X cm、X 度）→ 初始偏差范围，直接影响感知与控制方案
- 插孔高度 + 货叉厚度 + 上下余量 → 插取余量紧张度（只列数字与来源，不做可行性结论）
- 端部挡架/护栏是否遮挡叉孔
- 双层/多层堆叠取整垛还是单层

## 典型缺口（资料常缺，默认进缺失清单）

1. 载具全规格图纸（含叉孔尺寸公差）
2. 最坏情况（最歪、最破、最反光）的实物照片
3. 取放点实测高度与水平度
4. 峰值时段取放点的占用/拥堵情况
5. 放货精度的客户验收标准
