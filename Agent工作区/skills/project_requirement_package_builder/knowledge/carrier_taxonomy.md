# 载具归类知识（carrier_taxonomy）

> 用途：把资料中的搬运对象规范归类，并明确每类载具必须收集的字段。
> 硬约束：尺寸、材质、结构一律以资料原文/图片为准，缺失就写缺失。

## 载具类别

| 类别 | 英文 | 常见子类/说明 |
|---|---|---|
| 托盘 | pallet | 木托盘、塑料托盘、GMA（48×40in≈1219×1016mm）、CHEP（租赁蓝托）、欧标（1200×800）、定制 |
| 料笼 | cage | 金属网笼、可折叠、汽车行业异形件笼 |
| 料筐/料框 | bin / container | 金属/塑料，注意黑色吸光材质 |
| 货架类载具 | rack dolly | 带轮货架、移动货架 |
| 工装车/台车 | cart / dolly | 牵引拖挂小车（tugger cart）属于此类 |
| 料箱/纸箱 | tote / carton | 常与输送线配合 |
| 卷料/异形 | roll / non-standard | 卷材、桶、超长件 |

## 每类载具必须收集的字段（缺失 → 缺失清单）

**托盘类：**
- 长 × 宽 × 高；单双面；四向/两向进叉
- 叉孔：高度、宽度、间距（外间距）、墩位宽度（stringer/block）
- 底部结构（底板/垫块）、是否允许 ST/K 类车轮进入
- 材质与颜色（黑色/深色影响感知）、是否缠膜、膜是否遮挡叉孔
- 是否多规格混用、破损率、变形情况
- 满载重量、货物在托盘上的堆叠形式（单层/双层/是否超出托盘边缘）

**料笼/料筐类：**
- 外形尺寸、叉入方式（底部叉孔/裙边）、堆叠层数、变形程度
- 表面特征：网状/实心、反光、黑色

**工装车/拖挂小车类：**
- 车体结构、货位数量与间距、对接方式（挂钩/插入）
- 停放精度（角度偏差、位置浮动）、是否有定位辅助（反光条等）

## 感知风险特征关键词（出现即在 4.4 节提示）

黑色/深色载具、缠膜反光、透明膜、破损托盘、多规格混用、叉孔遮挡、
托盘不齐、货物超出托盘、堆叠歪斜、网状结构（点云稀疏）、潮湿/冰霜表面。

## 单位换算提醒

北美资料常用英寸/英尺：1 in = 25.4mm，1 ft = 304.8mm。
换算值要标注“由 xx 英寸换算”；转写中英尺/厘米混说的数值要复核并标注存疑。
