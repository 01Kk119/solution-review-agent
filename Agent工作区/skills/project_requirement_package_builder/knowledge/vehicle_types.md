# 车型识别知识（vehicle_types）

> **权威来源：`基础知识库/02_VisionNav_车型产品场景知识库.md`**（8 大系列 ST/K/P/E/Q/SL/R/VNA
> 的结构、能力、适配与禁忌以该文件为准，本文件不重复、只补充“从资料里认出车型”的方法）。
> 硬约束：不得凭型号名推断具体参数（载重/门架/尺寸），一切参数以选配单/规格书原文为准。

## 1. 从资料中识别车型的线索优先级

1. **选配结果单 / 亮点单**（最权威）：型号、数量、门架、货叉、电池、充电机等。
2. **功能规格书（Functional Spec）**：设备清单表（Project Quotation: Equipment）。
3. **信息收集表 Excel**：车型列、场景 sheet。
4. **会议纪要/转写**（口头信息，可信度次之）：注意 ASR 误听（见术语表）。
5. PPT / 图片（外观照片可辅助判断系列，但不能确定型号）。

## 2. 型号书写规范

- 公司型号形如 `VNE40-66`、`VNP...`、`VNQ...`：VN + 系列字母 + 数字组合。
- 输出时**保留完整原始型号字符串**（含后缀，如 `-CE`），不要拆解或改写。
- 型号后缀（如 CE）可能表示认证/区域版本——**不确定就标注“后缀含义需确认”**。
- 会议里口头说的“E 车 / Q 车 / P 车”映射到系列；具体型号仍以书面资料为准。

## 3. 需要抽取的车辆字段清单（资料里出现就必须记录）

- 型号 / 系列 / 数量
- 载荷（额定 / 实际货重）、载荷中心距
- 门架类型与高度、提升高度
- 货叉：长 × 宽 × 厚、外间距、是否可调、是否横移（sideshift）、特殊属具
- 电池：电压 / 容量 / 数量；充电机：功率 / 数量 / 类型（自动/手动）；换电方式（推车等）
- 导航方式、感知传感器（激光线数、相机）
- 防撞 / 安全配置（触边、防撞插件、声光）
- 定制项：颜色（含色号/RGB）、logo、加装件
- 软件版本要求（IGV 大版本）与调度架构（RCS / VFS）
- 每类信息**逐条带来源**

## 4. 常见坑

- 一个项目可能多车型混用（如 E 车装车 + Q 车牵引）——不要把不同车型的参数混在一起。
- 一期/二期项目的车型配置可能不同——分开记录，注明属于哪一期。
- 转写中“X 吨的货叉”“三吨半”等口头参数与选配单冲突时，列出双值并标记冲突。
- 客户说的 "AGV" 可能泛指我方所有车；客户自有设备（如客户的 tugger 小车）不要算进我方车辆清单，但要单独记录为“客户设备/交互对象”。
