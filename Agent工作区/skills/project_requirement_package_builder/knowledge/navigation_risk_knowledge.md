# 导航环境识别知识（navigation_risk）

> 用途：从资料中识别导航/定位/通过性相关信息与资料侧风险线索。
> 硬约束：只提“资料侧风险提示”，不下“导航做不了/能做”的结论。

## 必须整理的环境字段

**布局与地图：**
- layout 图（CAD/PDF/图片）是否提供、比例与完整性
- 库区/产线/月台/充电区分布；单双楼层、电梯、门（自动门/卷帘门/防火门/门禁）

**通道与通过性：**
- 主通道/支通道宽度（数值+位置）、单向/双向、会车设计
- 转弯空间、交叉路口、与人/客户叉车/客户 AGV 混行情况
- 通道是否与客户共用、未来是否可能变更（库位调整）

**地面与环境：**
- 地面材质（环氧/水泥/金属/格栅）、平整度、坡道、登车桥
- 反光地面、金属地面对激光的影响线索
- 光照（逆光、天窗、夜班照明）、粉尘、水汽、温湿度、冷库/洁净室
- 室内/室外/半室外；天花板高度与结构（钢梁——影响顶部特征定位的线索）

**定位辅助：**
- 反光条/反光柱/二维码等人工特征的位置与密度
- 环境特征丰富度（空旷区、长直走廊、动态货堆区——自然导航特征退化线索）

## 资料侧风险提示触发词

| 线索 | 提示 |
|---|---|
| 通道宽度接近车宽+载具宽 | 通道余量紧张，需确认实测宽度与会车策略 |
| 停车/对接偏差角度大（如 >10°） | 初始偏差大，需确认定位辅助方案 |
| 环境会变（货堆、拖车移动、库位调整） | 动态环境，地图维护与定位鲁棒性需评估 |
| 防火门/单线段 | 通行瓶颈与交管逻辑 |
| 登车桥/坡道 | 坡道通过性与防滑，载荷重心 |
| 人车混行/与客户设备共用通道 | 安全策略与交管需确认 |
| 深巷道（一头进出） | 倒车距离长、误差累积、避让困难 |
| 只有会议口头描述、无实测数据 | 全部标注“需现场确认” |

## 典型缺口

CAD 图纸、通道实测宽度、地面平整度报告、照明条件、
客户未来布局变更计划、消防与安全合规约束（当地法规）。
