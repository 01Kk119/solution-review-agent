# 场景归类知识（scene_taxonomy）

> 权威场景库与车型匹配规则见 `基础知识库/02_VisionNav_车型产品场景知识库.md` 第 12–14 章。
> 本文件给出“从资料中归类场景 + 每类场景必须追问什么”的操作指引。
> 硬约束：场景归类是 AI 归类行为，输出时标注「AI归类」；资料没写的场景属性不得脑补。

## 场景分类清单（按出现即登记）

| 场景类别 | 识别关键词（中/英） | 归类时必须记录的字段 |
|---|---|---|
| 平面搬运 | floor transfer、点到点、地面搬运 | 起终点、载具、距离/路线、是否双向 |
| 线库 / 深巷道存储 | floor storage、deep lane、线库、堆存 | 深度、宽度、高度/层数、先进先出还是只进不出、库存管理归属 |
| 输送线对接 | conveyor、滚筒线、取货口 | 输送线高度、取货口数量与命名、端部结构（挡架）、信号交互 |
| 货架取放 | rack、横梁式、高位 | 层高、货位尺寸、货架类型、是否对孔 |
| 堆叠/拆堆 | stacking、双层、堆垛 | 层数、由谁完成堆叠、堆叠质量 |
| 装卸车 | truck loading、dock、月台、车厢 | 车型（货柜/平板/飞翼）、登车桥、停车精度 |
| 牵引/拖挂装载 | tugger、AGT、cart loading | 拖挂小车结构、货位数、停放精度/角度 |
| 特殊存储区 | hospital lane、次品区、交接区 | 用途、监控方式、进出规则 |
| 室外 | outdoor、yard | 地面、天气、坡道 |
| 充电/换电 | charging station、换电 | 充电机数量位置、策略 |

## 每类场景的资料完备性检查（缺了就进缺失清单）

- **取货口/放货点**：位置、高度、数量、命名规则、左右空间、障碍物
- **通道**：宽度、单双向、会车、与人/客户设备共用情况
- **效率**：托/小时（区分均值与峰值）、班次、任务触发方式
- **交互**：信号来源（PLC/扫码/WMS/按钮）、异常时人工介入方式

## 归类注意

1. 一个项目通常是**多场景组合**（例：输送线取货 + 拖挂装载 + 线库存放）；按 workflow 拆开归类。
2. 客户口头叫法（如把牵引拖挂小车叫 "target 车位"）不等于标准场景名——用标准场景名归类，括号保留客户原话。
3. 判断“是否窄通道/是否高位”这类结论必须有数值或图片依据；只有 layout 视觉印象时标注「AI推断待确认」。
