## 0. 文件定位与使用方式

### 0.1 用途

让 AI 稳定、正确地理解并使用 VisionNav 的车型与场景知识，具体包括：

- 理解 VisionNav 的车型体系（ST / K / P / E / Q / SL / R / VNA）；
- 理解不同车型的结构差异（有无货叉、有无门架、有无平衡重、定向轮位置、举升能力、通过性、载重）；
- 理解不同车型适合什么场景、**不适合**什么场景；
- 理解装卸车、混合装卸、料笼堆叠、板货堆叠、线库、输送线对接、低 / 高位货架、极窄巷道、AMR 货架底层、牵引、室外重载等业务；
- 为产品方案生成、Roadmap、销售方案、技术方案、知识库问答、画图 Skill、Image2 渲染、SVG 工程示意图提供稳定上下文；
- **避免 AI 把车型画错、场景选错、结构理解错、货叉 / 车头方向画反。**

### 0.2 使用方式（读者是 AI 时的加载顺序）

1. 先读第 2 章**统一车辆坐标系与方向定义**（最高优先级硬规则，任何画图 / 写文档 / 仿真前必读）；
2. 再读第 3 章车型系列总览，建立整体分类；
3. 按需读第 4–11 章对应车型的详细结构与场景边界；
4. 做场景 / 选型时读第 12–14 章（场景库、匹配规则与速查表、不推荐组合）；
5. 生成图 / SVG / Image2 时读第 15 章使用提示；
6. 涉及具体几何尺寸时读第 16 章**待确认信息**，不确定的尺寸标注 estimated / 待从车型资料提取，**不得编造**。

### 0.3 硬约束（贯穿全文）

- **不编造未确认尺寸**：本文件不含车型真实长宽高、货叉长度、轴距、转弯半径、载重、举升高度等精确数值；这些统一列入第 16 章待确认，需从车型 PDF / 图片提取。
- **不把货叉方向和车头方向画反**（见第 2 章）。
- **K / Q 不画货叉、不画门架**；**ST / SL 定向轮在货叉 / 支腿区域**；**P / E 定向轮在车体上**；**R 画 reach 前移支腿 + 高门架**；**VNA 画侧向货叉**；**E 画大轮胎重载车体**；**Q 画拖挂钩**。
- 车型代号在不同语境下的口径以本文件为准；与旧材料冲突时以第 16 章标注为准。

## 1. VisionNav 产品体系总览

VisionNav（未来机器人）是一家**工业物流机器人公司**，核心是无人叉车，业务覆盖 AGV、AMR、自动装卸车、仓储机器人、视觉导航、智能取放、感知、调度系统、云施工、数字孪生仿真与机器人软件平台。业务场景集中在工业物流、仓储、制造业与海外客户项目，现场复杂、行业差异大、工况变化大、交付周期紧、项目非标多。

从**机构结构**看，公司车型可归为四大类：

| 大类 | 关键结构特征 | 车型 | 一句话定位 |
|---|---|---|---|
| 无货叉 · 顶升 / 牵引 | 无货叉、无门架 | K（顶升 AMR）、Q（牵引车） | K 钻入货物底部顶升；Q 后挂拖车牵引 |
| 支腿式 · 货叉在叉区 | 支腿 / 定向轮在货叉区域 | ST（低位搬运）、SL（狭窄举升）、R（前移高位） | 货叉侧有支腿；举升能力 ST<SL<R |
| 平衡重 · 裸货叉 | 车头有平衡重、定向轮在车体、裸货叉 | P（室内）、E（室外重载） | 裸货叉适应性强；E 是 P 的重载室外版 |
| 三向 · 侧向取放 | 侧向 90° 取放门架 | VNA（三向车） | 极窄巷道高库容，货叉侧向伸出 |

**结构判别树（AI 选型 / 画图时的快速判断）：**

1. 要**牵引拖挂**？→ Q。
2. 要**钻到货物 / 货架底部顶升**、无货叉？→ K。
3. 有**裸货叉 + 门架 + 车头平衡重、定向轮在车体**？→ P（室内轻载）或 E（室外重载 / 大料笼 / 四叉）。
4. 有**货叉 + 支腿 / 定向轮在货叉区**，举升很低（≈20cm）？→ ST；举升更高、车身 slim？→ SL；高门架 + reach 前移机构、面向高位货架？→ R。
5. **极窄巷道 + 货叉侧向 90° 取放**？→ VNA。

> 注：公司旧资料中还出现“堆高车”“前移车”等通用叫法。在本文件车型体系中，**前移式高位货架车对应 R 系列**；“堆高车 / 举升类”按举升高度与结构落到 SL / R；具体旧代号与本体系的映射见第 16 章待确认。

## 2. 统一车辆坐标系与方向定义（最高优先级硬规则）

> ⚠️ 这是 Maxwell 反复强调、并多次纠正 AI 的规则。任何 AI 在画图、写文档、生成仿真场景、解释控制 / 运动、做路径与 FOV 示意时，**必须无条件遵守**，绝对不能违反。把方向画反是被明确纠正过的典型错误。

**叉车 / 车辆坐标系（右手系）：**

- 采用**右手系**。
- **车头方向 / 舵轮方向 / 驾驶室方向 = +X**。
- **货叉方向 / 门架方向 / 叉取方向 = −X**（即货叉朝向是车头的反方向）。
- **坐标原点 = 两只定向轮中心连线的中点**。
- **舵轮通常位于 +X 方向**（车头侧）。
- **货叉与门架通常位于 −X 方向**。
- **“往前走” = 车辆朝车头方向运动 = +X**。
- **“往后退” = 车辆朝货叉方向运动 = −X**。

**必须区分的四个方向（易混，画图时务必分开标注）：**

| 概念 | 含义 | 默认方向 |
|---|---|---|
| 车辆朝向 | 车头 / 舵轮 / 驾驶室朝哪 | +X |
| 货叉朝向 / 门架朝向 | 货叉、门架、叉取结构朝哪 | −X（VNA 为侧向，见第 11 章） |
| 行驶方向 | 车此刻在往哪走 | +X 前进 / −X 后退 |
| 作业方向 | 取放动作朝哪发生 | 通常 −X（VNA 侧向） |

**硬性提醒：**

- 在**装卸车、货架取放、线库取放、FOV 视场、路径规划、车辆回路径、控制 Action 示意图**中，必须区分车辆朝向、货叉朝向、行驶方向、作业方向四者。
- **AI 绝对不能把货叉方向和车头方向画反。** 直觉里“叉车朝货叉方向开”是错的——叉车的“前进”是车头（无货叉一侧），货叉在车的 −X 侧。
- 不同车型运动学不同（ST / P / E / Q / K / SL / R / VNA），**不要用普通叉车概念套所有车**；尤其 K / Q 无货叉、VNA 侧向取放，坐标语义要按各自车型理解。

## 3. 车型系列总览

VisionNav 车型体系共 8 个系列：**ST / K / P / E / Q / SL / R / VNA**。

| 系列 | 中文定位 | 有货叉 | 有门架 | 举升能力 | 平衡重 | 定向轮位置 | 典型定位 |
|---|---|---|---|---|---|---|---|
| **ST** | 低成本平面搬运车 / 自动化地牛 | 有 | 无 | 极低（≈20cm\*） | 无 | 货叉中间 / 叉肩附近 | 低成本托盘平面搬运 |
| **K** | AMR / VNK 顶升搬运车 | 无 | 无 | 顶升盘顶升 | 无 | 车身（可原地转向） | 钻入底部顶升的 AMR |
| **P** | 室内平衡重叉车 | 裸货叉 | 有 | 中（3–4m 级为主） | 车头有 | 车体上 | 室内叉取 / 堆叠主力 |
| **E** | 室外重载大平衡重叉车 | 裸货叉 | 有 | 中高 | 车头有（更大） | 车体上 | 室外 / 重载 / 装卸车主力 |
| **Q** | 牵引车 / Tugger | 无 | 无 | 无 | 无 | 车中间 | 牵引拖挂 / Milk-run |
| **SL** | Slim Lift 狭窄空间举升车 | 有 | 部分 | 中（高于 ST） | 无 | 货叉 / 支腿区 | 窄空间输送线 / 低位货架 |
| **R** | Reach Truck 前移式高位货架车 | 有 | 高门架 | 高（6–8m 常见，最高约 12m*） | 无（支腿式） | 支腿系统 | 高位货架入 / 出库 |
| **VNA** | 三向车 / 极窄巷道高位货架车 | 有（侧向） | 高门架 | 高 | — | — | 极窄巷道高库容 |

\* 带 * 的高度为方向性说明，具体以车型资料为准（见第 16 章）。

**关键结构对照记忆点：**

- **有没有货叉**：K / Q 无货叉；其余有。
- **有没有平衡重**：只有 P / E 是“车头平衡重 + 裸货叉”结构。
- **定向轮在哪**：ST / SL 在货叉 / 支腿区；P / E 在车体上；这是区分平衡重车与支腿车的关键。
- **举升高度梯度**：ST（≈20cm）< SL（低位）< P（3–4m 级）≈ E（中高）< R（6–12m）；VNA 面向高位且极窄巷道。
- **取放方向**：绝大多数车沿 −X 取放；**只有 VNA 是侧向 90° 取放**。

## 4. ST 系列：低成本平面搬运车 / 自动化地牛

ST 是较小的车型，本质是**低成本平面搬运车**，可理解为自动化的小地牛 / 自动化托盘搬运车（automated pallet jack）。

### 4.1 核心结构
- 有货叉；**没有完整门架系统**。
- 举升高度很低，约 **20cm** 左右，主要把货物从地面抬起一点用于平面搬运。
- **定向轮位于货叉中间区域，通常靠近叉肩位置**。
- 货叉方向 −X；车头 / 舵轮方向 +X。
- 整体结构简单、成本低，更像自动化的手动托盘车 / 地牛，而非标准高门架叉车。

### 4.2 核心能力
平面搬运、地面托盘取放、线库 / 线边库取放、托盘类货柜车装 / 卸车、低成本自动化搬运。

### 4.3 适合场景
托盘类载具、地面取放、线边库 / 线库、货柜车中能被货叉插入的托盘类货物、不需要高举升的搬运场景。

### 4.4 不适合场景
高位货架、需要高门架举升的场景、无法让货叉和轮子进入的料笼 / 特殊载具、重载室外、大型料筐、四叉装卸。

### 4.5 和其他车型的区别
- 相比 K：ST 有货叉，K 无货叉（顶升式）。
- 相比 SL：ST 举升能力很低，SL 举升更强。
- 相比 P / E：ST 不是平衡重叉车，没有高门架和裸货叉适应性。
- 相比 R：ST 不是高位货架车。

### 4.6 AI 画图 / 生成图提示
- 画成**低矮托盘搬运车**，不要画高门架；定向轮在货叉区域 / 叉肩附近；不要画成 P / E 平衡重叉车。
- 图像生成描述词：`low-profile autonomous pallet truck` / `automated pallet jack` / `autonomous pallet mover`。
- **不要**描述为 `high mast forklift`。

## 5. K 系列：AMR / VNK 顶升搬运车

K 系列是 **AMR / VNK**，小车顶升搬运方案。

### 5.1 核心结构
- **没有货叉、没有门架**。
- 通过**顶升盘 / lift plate / lifting platform** 顶升货物或载具。
- 需要**钻入货物、料架、货架或带架载具下方**后顶升。
- 可**原地转向**，占地空间小，成本相对更低。
- 适合底部有空间、允许 AMR 进入下方的载具与货架。

### 5.2 核心能力
顶升搬运、AMR 货架搬运、带架托盘 / 料架搬运、小空间平面搬运、原地旋转、线边物料转运、货架底层运行。

### 5.3 适合场景
AMR 货架、货架底层搬运、可顶升料架、带架载具、小空间搬运、需要车身小 + 原地转向的场景。

### 5.4 不适合场景
裸货叉插取、需从侧面插入托盘孔但车无法进入货物底部的场景、高位货架、装卸车常规叉取、料笼底部结构不允许车进入的场景、牵引场景。

### 5.5 和其他车型的区别
- 相比 ST：K 无货叉、靠顶升盘；ST 有货叉。
- 相比 P / E：K 不是叉车，不具备裸货叉适应性。
- 相比 Q：K 是顶升搬运，Q 是牵引。
- 相比 SL：K 靠进入货物下方顶升，SL 靠货叉举升。

### 5.6 AI 画图 / 生成图提示
- 画成**低矮 AMR 小车**；**不能画货叉、不能画门架**；要画**顶升盘 / 顶升平台**；可画 AMR 钻入货架底层。
- 图像生成描述词：`low-profile autonomous mobile robot with lift plate` / `compact warehouse AMR` / `under-rack lifting robot`。
- Negative prompt：`no forks` / `no mast` / `no counterbalance forklift`。

## 6. P 系列：室内平衡重叉车

P 系列是**室内平衡重叉车**（compact indoor autonomous counterbalance forklift）。

### 6.1 核心结构
- 有**裸货叉**、有**门架**。
- **定向轮在车体上**，不在货叉中间。
- 车头 / 舵轮 / 驾驶室方向 +X；货叉 / 门架方向 −X。
- **车头侧有平衡重**，用于抵消货叉侧载荷，保证载货后重心仍在车辆支撑区域内。
- 货叉是**裸货叉**，适应性比 ST / SL 这类支腿 / 轮子在叉区的车型更强。
- 轮子偏室内叉车轮，通过性不如 E；载重通常小于 E。
- 举升高度通常适合 **3–4m 级**，极限或定制可更高，但不是主力高位车型。

### 6.2 平衡重逻辑（结构原理）
- 货叉侧载货后，货物重心可能落在定向轮支点外侧；
- 若无平衡重，车辆可能前倾；
- 因此在车头 / 舵轮侧布置平衡重，用车头侧重量抵消货叉侧载荷；
- 定向轮附近可理解为前后稳定性的关键支点区域；
- 只要整车重心保持在支撑区域内，车辆就能稳定。

### 6.3 核心能力
平面搬运、板货堆叠 / 拆堆、料笼堆叠 / 拆垛、低 / 中位横梁式货架、输送线 / 滚筒线对接、尾掏车 / 货柜车装卸、平板车 / 飞翼车两侧装卸、室内装卸与搬运。

### 6.4 适合场景
室内托盘搬运、室内板货堆叠、小 / 中型料笼堆叠、3–4m 左右横梁式货架、输送线取放、室内尾掏车装卸、室内或轻载平板 / 飞翼车两侧装卸。

### 6.5 不适合场景
室外复杂地面、重载大料筐、大轮胎高通过性场景、超高位货架、极窄巷道、大型四叉重载装卸。

### 6.6 和其他车型的区别
- 相比 ST / SL：P 是平衡重裸货叉，叉取适应性更强。
- 相比 E：P 更偏室内、轻载、小型，通过性和载重不如 E。
- 相比 R：P 不是前移高位车，不适合 6–12m 高位货架。
- 相比 K：P 是叉车，K 是 AMR 顶升。
- 相比 Q：P 能叉取，Q 只能牵引。

### 6.7 AI 画图 / 生成图提示
- 画成**标准室内平衡重叉车**：有裸货叉与门架；定向轮在车体上；车头 +X 侧有平衡重 / 驾驶室；货叉 −X 侧有门架和货叉。
- **不要**把定向轮画到货叉中心；不要画成 R 车支腿结构；不要画成 E 车大轮胎重载结构。
- 图像生成描述词：`compact indoor autonomous counterbalance forklift` / `red and black autonomous forklift` / `indoor warehouse forklift`。

## 7. E 系列：室外重载大平衡重叉车

E 系列是**大平衡重 / 室外重载叉车**，可理解为 **P 系列的重载、室外、高通过性版本**。

### 7.1 核心结构
- 与 P 同属平衡重结构：有裸货叉、有门架、车头有平衡重、定向轮在车体上。
- 车头 / 舵轮方向 +X；货叉 / 门架方向 −X。
- **轮胎更大、通过性更强、车体更大更厚重、载重更高**。
- 可支持更大尺寸货物、更大料筐、更复杂地面。
- **四叉 / Single Double Fork / 双叉四叉类装卸通常更偏 E 系列。**

### 7.2 核心能力
原则上覆盖 P 的大部分场景，并扩展到更重、更大、更室外、更复杂的场景：平面搬运、板货堆叠 / 拆堆、料笼堆叠 / 拆垛、大料筐搬运、室外搬运、重载搬运、货柜车 / 尾掏车装卸、平板车 / 飞翼车两侧装卸、混合装卸、料笼装卸、四叉装卸、Single Double Fork 装卸、大型载具搬运。

### 7.3 适合场景
室外装卸、重载装卸、大料筐、大料笼、混合装卸、需要较强通过性的场景、平板 / 飞翼车两侧装卸、尾掏车 / 货柜车装卸、四叉 / 双叉四叉场景。**客户真实装卸车项目中的主力车型。**

### 7.4 不适合场景
极小空间 + 低成本 AMR 顶升场景、需要极小转弯半径的狭窄线边库、高位货架主力场景、极窄巷道 VNA 场景、单纯轻载室内场景（可能成本偏高）。

### 7.5 和其他车型的区别
- 相比 P：E 更重载、更大轮胎、更适合室外与复杂地面。
- 相比 R：E 是平衡重，不是前移高位车。
- 相比 K：E 是叉车，不是 AMR 顶升。
- 相比 Q：E 能叉取，Q 只能牵引。
- 相比 SL / ST：E 体积更大、载重更高，但不如 SL / ST slim 或低成本。

### 7.6 AI 画图 / 生成图提示
- 画成**大型平衡重叉车**：比 P 更大更厚重，轮胎明显更大，车体更重载；货叉可支持普通双叉、四叉、Single Double Fork；车头 +X 侧明显有大平衡重 / 大轮胎结构；货叉 −X 侧有门架和裸货叉。
- 图像生成描述词：`outdoor heavy-duty autonomous counterbalance forklift` / `heavy-duty autonomous forklift with large tires` / `industrial outdoor loading dock forklift`。
- **混合装卸、重载料笼、平板 / 飞翼车、四叉装卸优先使用 E 系列。**

## 8. Q 系列：牵引车 / Tugger

Q 系列是**牵引车**（在旧材料中也称“Q 车 / 自动拖挂”）。

### 8.1 核心结构
- **没有货叉、没有门架**。
- 后部有**拖挂钩 / towing hook**，类似机场牵引车或汽车行业牵引车。
- 用于牵引料车、拖车、台车。
- 车头为舵轮方向 +X；车中间有定向轮；后方连接拖挂系统。

### 8.2 核心能力
室内 / 室外牵引、料车牵引、拖车牵引、台车牵引、Milk-run 循环配送、汽车行业厂内物流牵引。

> 产品能力域参考（旧材料中 Q 车软件功能清单的十大能力域，可用于产品方案 / Roadmap 展开）：① 产品基础能力适配；② 导航定位；③ 控制与行驶；④ 牵引车与自动拖挂；⑤ 充电；⑥ 安全防护；⑦ 调度中控与协议；⑧ HMI 与现场交互；⑨ 运维保障；⑩ 生产与交付。自动拖挂技术点：挂点识别、车辆对准、牵引机构控制、挂接状态检测、脱挂、异常保护、牵引路径规划、牵引稳定性、调度流程、HMI 提示。

### 8.3 适合场景
汽车行业料车牵引、厂内循环配送、多料车拖挂、室内 / 室外牵引物流、类似机场牵引的拖挂场景。

### 8.4 不适合场景
叉取、举升、货架取放、装卸车叉取、料笼堆叠、板货堆叠、AMR 顶升。

### 8.5 和其他车型的区别
- Q 是牵引车，不是叉车；核心是**拖挂**，不是顶升或叉取。
- 相比 K：Q 牵引，K 顶升。
- 相比 P / E：Q 不能叉取。
- 相比 ST / SL：Q 不是托盘搬运或举升车。

### 8.6 AI 画图 / 生成图提示
- **不要画货叉、不要画门架**；要画**拖挂钩**；支持后方连接多个料车；车体可画成牵引车小车头。
- 图像生成描述词：`autonomous tugger vehicle` / `autonomous towing tractor` / `autonomous tugger pulling material carts` / `factory milk-run logistics vehicle`。
- Negative prompt：`no forks` / `no mast` / `not a forklift`。

## 9. SL 系列：Slim Lift 狭窄空间举升车

SL 是 **Slim Lift**，狭窄空间举升搬运车。

### 9.1 核心结构
- 类似 ST 的支腿 / 轮子结构，但具备**更强举升能力**。
- 定向轮 / 支腿位于货叉中心或货叉区域；有支腿结构、有货叉、有一定举升能力。
- 比 ST 能举升更高；不属于 P / E 那种平衡重裸货叉结构。
- 车身 slim（窄），转弯半径小、通行半径小。

### 9.2 核心能力
平面搬运、滚筒线对接、输送线取放、低位横梁式货架、窄空间搬运、线边库搬运、低位举升取放。

### 9.3 适合场景
空间狭窄的线边库、输送线 / 滚筒线对接、低位横梁式货架、对车身宽度 / 转弯半径 / 通行半径敏感的场景、需要比 ST 更强举升但不需要 P / E / R 的场景。

### 9.4 不适合场景
尾掏车 / 货柜车装卸、室外重载、高位货架、大型料筐、四叉装卸、重载混合装卸。

### 9.5 和其他车型的区别
- 相比 ST：SL 举升能力更强。
- 相比 P / E：SL 更 slim，但不是平衡重裸货叉，叉取适应性不同。
- 相比 R：SL 不是高位前移车。
- 相比 K：SL 有货叉，K 是顶升 AMR。
- 相比 Q：SL 能举升，Q 只能牵引。

### 9.6 AI 画图 / 生成图提示
- 画成 **slim lift 结构**：车体细长、窄；支腿 / 定向轮在货叉区域；有货叉和一定举升结构。
- **不要**画成 P / E 平衡重车；不要画成 R reach truck。
- 图像生成描述词：`slim autonomous lift truck` / `narrow aisle autonomous lift truck` / `autonomous lift truck for conveyor docking`。

## 10. R 系列：Reach Truck 前移式高位货架车

R 系列是 **Reach Truck**，前移式高位货架车。

### 10.1 核心结构
- 有门架、有 **reach 前移机构**，货叉可前移取放。
- 有**支腿系统**，适合高位货架。
- 取放时门架前移，不取放时门架收回。
- 货叉方向仍通常沿车辆作业方向（−X），**不是** VNA 那种侧向 90° 取放。
- 相比 P / E，R 更适合高位货架和更高举升；相比 VNA，R 仍需要较大的直角堆垛宽度。

### 10.2 核心能力
高位横梁式货架取放、高位穿梭式货架取放、托盘入库 / 出库、高位仓储、货架巷道作业、**高位 / 货架相关的输送线对接**（仅限货架 / 高位场景，非狭窄空间输送线的主力，那类应选 SL）。常见 **6–8m** 高度，最高可到约 **12m**（以车型资料为准，见第 16 章）。

### 10.3 适合场景
高位货架、高位横梁式货架、高位穿梭式货架、货架巷道、托盘高位入库 / 出库。

### 10.4 不适合场景
尾掏车装卸、平板 / 飞翼车装卸、车厢内装卸、线库板货堆叠、常规料笼堆叠、狭窄线边库、低成本平面搬运、AMR 顶升、牵引。

### 10.5 为什么不适合装卸车
- R 车门架高，通常无法进入车厢；
- 车体和支腿结构不适合车厢内装卸；
- 装卸车更适合 P / E / ST 等车型，重载和室外优先 E。

### 10.6 和其他车型的区别
- 相比 P / E：R 是前移车，有 reach 机构和高门架，适合高位货架。
- 相比 VNA：R 不是三向车，货叉不是侧向 90° 取放。
- 相比 SL：R 更高位、更重、更适合货架，不是 slim 低位举升车。
- 相比 K：R 是高位货架叉车，K 是 AMR 顶升。

### 10.7 AI 画图 / 生成图提示
- 画成 **reach truck**：门架明显更高；支腿结构明显；货叉在 −X 侧；支腿可进入货架底部区域；场景要体现高位货架。
- **不要**画成 P / E 平衡重车；不要画成 VNA 三向车。
- 图像生成描述词：`autonomous reach truck operating at high pallet racks` / `high-mast autonomous reach truck` / `reach truck in high rack warehouse`。
- Negative prompt：`not a counterbalance forklift` / `not an AMR` / `not a tugger` / `not trailer loading`。

## 11. VNA：三向车 / 极窄巷道高位货架车

VNA 是**三向车 / 三向式 R 车**，用于 Very Narrow Aisle（极窄巷道）。

### 11.1 核心结构
- 车辆**沿货架巷道方向前后行驶**。
- 货叉可相对车辆运动方向**旋转或伸出 90°**。
- 取放货时，**货叉方向垂直于车辆行驶方向**（侧向取放）。
- 能在很窄巷道内完成高位取放。
- 本质是为了**减少普通 R 车所需的直角堆垛宽度**。
- 车辆和门架系统通常比普通 R 更复杂、更贵。

### 11.2 关键几何硬事实（Maxwell 反复纠正过 AI，必须遵守）
> 1. VNA 的**车体和货叉运动方向不一致**（不是普通叉车那样简单一致）；
> 2. VNA 可能需要**车头朝向主通道方向，货叉侧向面向货架**（可侧向取放）；
> 3. **VNA 货架是单列结构：两个立柱中间只能放一个货位**（不要画成多深位 / 多列货架）；
> 4. AMR 可在**货架一层 / 底层**穿行，相关场景要考虑货架底层横梁、空间与车辆高度；
> 5. 画图 / 仿真 / 写文档时，车头、货叉、货架、巷道方向**绝不能画错**。

### 11.3 核心能力
极窄巷道高位取放、高位货架作业、高库容仓储、电商物流仓储、三向取放、提升库容利用率。

### 11.4 适合场景
极窄巷道、高位货架、高库容仓库、电商物流、日本 / 韩国 / 欧洲 / 亚马逊类高库容场景、对库容要求极高的仓储项目。

### 11.5 不适合场景
普通平面搬运、线库搬运、装卸车、料笼堆叠、牵引、AMR 顶升、室外重载搬运。

### 11.6 和其他车型的区别
- **相比 R（最关键对比）**：R 车需要**直角堆垛宽度**，通常需要一定转向空间来对货架取放；VNA **沿巷道前后走，货叉侧向 90° 取放**，可在更窄巷道中作业、提高库容；VNA 成本更高，门架 / 货叉系统更复杂。
- **相比 P / E**：VNA 是侧向 90° 取放、面向极窄巷道高位高库容，不是平衡重裸货叉车。
- **相比 K / Q**：VNA 有货叉和高门架做高位取放，不是顶升（K）或牵引（Q）。
- **相比 ST / SL**：VNA 面向极窄巷道高位货架，不是低位平面搬运（ST）或窄空间低位举升（SL）。

### 11.7 AI 画图 / 生成图提示
- 两侧高位货架、中间极窄巷道；车辆沿巷道方向；货叉侧向伸出到左侧或右侧货架。
- **必须标明车辆行驶方向和货叉伸缩方向**；不要画成普通 R 车；不要画成普通叉车转 90° 进货架。
- 图像生成描述词：`VNA trilateral forklift` / `very narrow aisle truck` / `side-shifting forks` / `tall pallet racks` / `high-density warehouse`。

> 素材说明：当前公司可能没有完整的 VNA 车型素材 / 参考图，但知识库需保留该车型语义与几何约束。VNA 是否有公司内部素材，见第 16 章待确认。

## 12. 典型业务场景知识库

每个场景包含：场景定义、推荐车型、可选车型、不推荐车型、关键原因、常见误解、AI 使用提示。

### 12.1 平面搬运
- **场景定义**：把托盘 / 载具在地面水平搬运，不需要高举升。
- **推荐车型**：ST、K、P、E、SL。
- **可选车型**：—。
- **不推荐车型**：Q（只能牵引，不能取放）、R（前移式高位货架车，纯平面搬运大材小用、成本高）、VNA（面向极窄巷道高位，不做平面搬运）。
- **关键原因**：ST 低成本托盘平面搬运；K 顶升式平面搬运；P / E 叉车式平面搬运；SL 狭窄空间平面搬运且兼具一定举升。
- **常见误解**：把 K 当成有货叉的叉车；用 R 做平面搬运（浪费高位能力）。
- **AI 提示**：默认低成本托盘 → ST；带架可顶升 → K；狭窄空间 → SL。

### 12.2 线库 / 线边库
- **场景定义**：产线边的物料缓存 / 取放，空间常狭窄。
- **推荐车型**：ST、SL、P、K。
- **可选车型**：E（空间充裕、重载时）。
- **不推荐车型**：R（门架高、不适合窄线库）、VNA（用于极窄高位货架，不是线库）。
- **关键原因**：ST 低成本托盘线库；SL 空间狭窄且需少量举升；P 可做板货 / 料笼叉取堆叠；K 适合可顶升 / 带架载具；E 空间狭窄或轻载低成本时非优先。
- **常见误解**：把线库等同于货架巷道，误用 R / VNA。
- **AI 提示**：窄 + 需举升 → SL；低成本托盘 → ST；带架可顶升 → K。

### 12.3 板货堆叠 / 拆堆
- **场景定义**：托盘上带货的结构化货物的堆叠与拆堆。
- **推荐车型**：P、E。
- **可选车型**：—。
- **不推荐车型**：K（无货叉）、Q（牵引）、R（前移高位车，不适合线库板货堆叠）。
- **关键原因**：板货是托盘上带货的结构化货物，P / E 裸货叉适合叉取和堆叠；E 适合更大 / 更重 / 更室外的板货。
- **常见误解**：认为 R 能做板货堆叠（R 面向高位货架，不是板货堆叠）。
- **AI 提示**：室内轻中载 → P；更大更重更室外 → E。

### 12.4 料笼堆叠 / 拆垛
- **场景定义**：金属料笼（常见于汽车行业，装发动机、钣金件、轮胎等异形件）的堆叠与拆垛。
- **推荐车型**：P、E。
- **可选车型**：ST / K / SL（取决于料笼底部结构，通常非主力）。
- **不推荐车型**：R（常规料笼堆叠不推荐）、Q（牵引）。
- **关键原因**：小料笼可用 P；大料筐 / 大料笼 / 重载 / 室外优先 E；ST / K / SL 是否适合取决于料笼底部结构。
- **常见误解**：忽视料笼结构（可能变形、边框细、反光 / 黑色）对识别与插取的影响。
- **技术要点**：料笼识别 → 位姿估计 → 点云 / 图像融合 → 插取点计算 → 堆叠位姿校正 → 货叉高度 / 横移控制 → 车辆微调 → 安全检测 → 多层堆叠策略。适合做仿真与数据闭环。
- **AI 提示**：默认 P / E；重载室外大料笼 → E。

### 12.5 输送线 / 滚筒线对接
- **场景定义**：与输送线 / 滚筒线对接取放。
- **推荐车型**：SL、P、E；**R（仅限高位 / 货架相关的输送线场景）**。
- **可选车型**：—。
- **不推荐车型**：ST（举升高度低，只能非常低位）、K（只适合可顶升载具，非标准输送线叉取）、Q（牵引）。
- **关键原因**：SL 因 slim 和举升能力适合狭窄空间对接（狭窄空间输送线对接的默认选型）；P / E 有门架货叉也能对接；R **只在高位 / 货架相关的输送线场景**才适用，不是普通输送线对接主力。
- **常见误解**：用 ST 对接需要一定高度的输送线（举升不够）。
- **AI 提示**：狭窄空间 → SL；常规 → P / E；高位相关 → R。

### 12.6 低位横梁式货架
- **场景定义**：低 / 中位横梁式货架的托盘取放。
- **推荐车型**：SL、P、E。
- **可选车型**：R（若已属高位则转 R）。
- **不推荐车型**：K（无货叉）、Q（牵引）。
- **关键原因**：SL 适合支腿能进入货架底部、空间狭窄的低位货架；P / E 处理普通低 / 中位横梁式货架，P 常见 3–4m，E 适合更大载重。
- **常见误解**：把低位货架与高位货架混同，误配 R / VNA。
- **AI 提示**：窄空间低位 → SL；常规低中位 → P / E。

### 12.7 高位货架
- **场景定义**：普通高位横梁式 / 穿梭式货架的托盘入 / 出库。
- **推荐车型**：R、VNA。
- **可选车型**：—。
- **不推荐车型**：P / E（不是主力高位货架车）、ST / SL / K / Q。
- **关键原因**：R 适合普通高位横梁式 / 穿梭式货架；VNA 适合极窄巷道高库容货架。
- **常见误解**：用 P / E 做高位货架主力。
- **技术要点**：多层货架、高位取放、货位间距小、立柱遮挡、横梁影响感知、插取精度要求高、安全风险高。
- **AI 提示**：普通高位 → R；极窄巷道高库容 → VNA。

### 12.8 极窄巷道高位货架
- **场景定义**：Very Narrow Aisle，巷道极窄、货架密集、追求库容利用率。
- **推荐车型**：VNA。
- **可选车型**：—。
- **不推荐车型**：R（需直角堆垛宽度，做不到 VNA 的窄）、其余全部。
- **关键原因**：VNA 沿巷道行驶、货叉侧向 90° 取放，核心价值是减少直角堆垛宽度、提高库容。
- **常见误解**：用普通 R 车逻辑理解 VNA；把 VNA 货架画成多列 / 多深位。
- **AI 提示**：一律 VNA；严格遵守第 11.2 节几何硬事实。

### 12.9 尾掏车 / 货柜车装卸
- **场景定义**：从车尾进入车厢的货柜车 / 尾掏车装 / 卸货。
- **推荐车型**：E、P、ST。
- **可选车型**：K（仅在特殊可顶升结构下，非常规）。
- **不推荐车型**：R（门架高、无法进车厢）、SL（不适合尾掏车 / 货柜车装卸）、Q（牵引）、VNA（三向高位货架车，不做车厢内装卸）。
- **关键原因**：E 是重载和室外装卸主力；P 用于室内或较轻载；ST 用于托盘类载具货柜车装卸（不适合无法插取的料笼）。
- **常见误解**：用 R / SL 做车厢内装卸。
- **技术要点**：车厢内光照变化、空间狭窄、停位偏差、登车桥姿态变化、地面不平、托盘位置不规则、Pattern 多样、遮挡、人货车混杂，需与导航 / 控制 / 取放策略配合。技术链路：相机 → 点云 / 深度 → 结构识别 → 位姿估计 → 取放点计算 → 车辆位姿修正 → 货叉插取策略 → 控制 → 异常检测 → HMI → 现场配置 → 日志回放 → 测试验证 → SOP。
- **AI 提示**：重载 / 室外 → E；室内轻载 → P；托盘类低成本 → ST。

### 12.10 平板车 / 飞翼车两侧装卸
- **场景定义**：平板车 / 飞翼车（栏板或飞翼打开后）从车辆两侧装卸；中国、日本、欧洲较常见。
- **推荐车型**：E、P。
- **可选车型**：—。
- **不推荐车型**：R、SL、K、Q、VNA。
- **关键原因**：E 更适合室外、重载、大料筐；P 用于室内或较轻场景。
- **常见误解**：忽视两侧装卸的作业方向与车辆朝向关系（见第 2 章）。
- **AI 提示**：默认 E（室外重载优先），室内轻载可 P。

### 12.11 混合装卸
- **场景定义**：车厢内混合托盘、纸箱、蓝色料笼、黑色料框、异形载具、空位；满箱 / 半箱混合、不同高度尺寸混合、规则与非规则区域混合。
- **推荐车型**：E、P（**优先 E**）。
- **可选车型**：—。
- **不推荐车型**：R、SL、K、Q、VNA。
- **关键原因**：E 更适合真实销售场景中的重载、室外、复杂装卸；P 用于轻载或室内版本。
- **常见误解**：把混合装卸当成单一 Pattern；混合装卸图中不区分不同载具类型和空间占用。
- **技术难点**：视觉识别难、场景建模难、Pattern 不固定、取放顺序复杂、异常处理复杂、规划与控制强耦合、现场调参成本高、验收指标不好定义。分阶段策略：规则系统产品化 → 感知增强 → 数据采集 → 仿真建模 → 部分策略学习 → VLA 预研接入 → 小范围验证 → 产品化评估。
- **AI 提示**：**用户说“混合装卸”默认优先 E**；图中区分载具类型与空位。

### 12.12 四叉 / Single Double Fork 装卸
- **场景定义**：一次叉取多托货物的四叉 / 双叉四叉 / Single Double Fork 装卸。
- **推荐车型**：E。
- **可选车型**：—。
- **不推荐车型**：ST / SL / K / Q / R；P 一般不做大型四叉重载。
- **关键原因**：四叉 / Single Double Fork 对载重、车宽、结构强度要求高，优先 E。
- **常见误解**：用轻载车型做四叉重载装卸。
- **AI 提示**：一律 E；货叉可画普通双叉、四叉、Single Double Fork。

### 12.13 AMR 货架底层运行
- **场景定义**：AMR 钻入货架或载具底部、通过顶升盘顶升货物，在货架底层运行。
- **推荐车型**：K。
- **可选车型**：—。
- **不推荐车型**：所有带货叉 / 门架的叉车（ST / P / E / SL / R / VNA）、Q。
- **关键原因**：K 系列 AMR 可钻入货架 / 载具底部，靠顶升盘顶升，适合小空间、原地旋转、底层搬运。
- **常见误解**：把 K 画成有货叉的叉车。
- **AI 提示**：**用户说“AMR 货架底层”默认 K**；不画货叉 / 门架，画顶升盘。

### 12.14 牵引 / 拖挂 / Milk-run
- **场景定义**：后方连接料车 / 台车 / 拖车做循环配送，适合汽车行业和厂内循环配送。
- **推荐车型**：Q。
- **可选车型**：—。
- **不推荐车型**：所有叉车与 K。
- **关键原因**：Q 无货叉，专门做牵引，后方连接多料车。
- **常见误解**：期望 Q 具备叉取 / 举升能力。
- **AI 提示**：**用户说“牵引”默认 Q**；画拖挂钩 + 多料车。

### 12.15 室外重载
- **场景定义**：室外、重载的叉取 / 装卸或牵引。
- **推荐车型**：E、Q。
- **可选车型**：—。
- **不推荐车型**：P（室外通过性较弱）、K / ST / SL（通常非室外重载主力）、R / VNA（面向高位货架，不是室外重载搬运）。
- **关键原因**：E 适合室外重载叉取和装卸；Q 适合室外牵引。
- **常见误解**：用 P 承担室外复杂地面重载。
- **AI 提示**：叉取 / 装卸 → E；牵引 → Q。

## 14. 不推荐车型与场景组合

每条都给出原因，供 AI 主动规避错误选型 / 错误画图。

- **R 不推荐装卸车**：R 门架高，通常无法进入车厢；车体和支腿结构不适合车厢内装卸。装卸车应选 P / E / ST，重载室外优先 E。
- **R 不推荐线库板货堆叠**：R 是前移式高位货架车，面向货架巷道高位入 / 出库，不是线库 / 板货堆叠的经济或结构合适选择。
- **R 不推荐常规料笼堆叠**：常规料笼堆叠（尤其汽车行业地面 / 低中位）应由 P / E 裸货叉完成，R 的高门架 + 支腿结构不匹配。
- **SL 不推荐尾掏车 / 货柜车装卸**：SL 是狭窄空间低位举升车，举升与结构不足以支撑车厢内装卸；应选 E / P / ST。
- **K 不适合裸货叉插取**：K 无货叉，靠顶升盘钻入货物底部顶升；任何需要从侧面插入托盘孔取放的场景都不适用。
- **Q 不适合任何叉取 / 举升场景**：Q 无货叉、无门架，只能牵引拖挂；叉取、举升、货架取放、装卸车、料笼 / 板货堆叠、AMR 顶升都不适用。
- **ST 不适合高位货架**：ST 举升高度极低（≈20cm）、无完整门架，只能做低位平面搬运，无法上高位货架。
- **P 不适合重载室外复杂地面**：P 是室内平衡重叉车，轮子偏室内、通过性弱、载重较低；室外复杂地面 / 重载应选 E。
- **E 不适合强调极小空间、低成本 AMR 顶升的场景**：E 车体大、重载、通过性强但转弯半径与成本高，不适合极小空间窄线边库或低成本 AMR 顶升；这类场景应选 K / ST / SL。
- **VNA 不适合普通平面搬运和装卸车**：VNA 面向极窄巷道高位高库容，侧向取放、系统复杂成本高；普通平面搬运用 ST / K / P，装卸车用 E / P / ST。

## 17. 摘要版速查表

**一句话记住每个车型：**

| 车型 | 一句话 |
|---|---|
| ST | 有货叉、无门架、举升≈20cm，低成本自动化地牛，托盘平面搬运 |
| K | 无货叉、无门架，顶升盘钻入底部顶升的 AMR，可原地转向 |
| P | 裸货叉 + 门架 + 车头平衡重、定向轮在车体，室内叉取 / 堆叠主力（3–4m 级） |
| E | P 的室外重载版：大轮胎、大平衡重、高载重，装卸车 / 混合装卸 / 四叉主力 |
| Q | 无货叉、后挂拖挂钩，牵引料车 / Milk-run |
| SL | Slim Lift，窄车身 + 货叉 + 一定举升，窄空间输送线 / 低位货架 |
| R | Reach Truck，reach 前移 + 高门架 + 支腿，高位货架入 / 出库（6–12m） |
| VNA | 三向车，沿巷道走、货叉侧向 90° 取放，极窄巷道高库容 |

**结构速判：**
- 无货叉：K（顶升）、Q（牵引）。
- 平衡重裸货叉：P（室内）、E（室外重载）。
- 支腿 / 货叉区定向轮：ST（低）、SL（中）、R（高位前移）。
- 侧向取放：VNA。

**场景 → 车型默认：**
低成本平面托盘搬运→ST｜AMR 顶升→K｜室内叉取堆叠→P｜混合装卸 / 重载 / 四叉 / 室外叉取→E｜牵引→Q｜窄空间输送线对接→SL｜高位货架→R｜极窄巷道高库容→VNA。

**三条绝不能错：**
1. 货叉方向 = −X，车头 = +X，绝不画反（第 2 章）。
2. K / Q 无货叉、无门架（画顶升盘 / 拖挂钩）。
3. VNA 货架单列、两立柱间一个货位，货叉侧向取放（第 11.2 章）。
